# Witness operator trial

Status: invitation draft; no invitations sent. Run after the evidence receipt
implementation passes review and is deployed through the existing process.

## Invitation

Submit one public-source claim you need checked before acting on it. Include the
HTTPS URL, the field to extract, the expected value or comparison, and what you
would do with the result. Do not send credentials or private source material.

Witness returns an observation receipt and the retained source text. Another
agent can verify the signature against a public key you trust independently and
replay the check offline. The receipt records when Witness retrieved the source;
it does not establish an uncollected historical state or the publisher's honesty.

## Five-operator record

Use an operator alias, not personal details. Record:

- Requested task and whether the existing assertion grammar can express it.
- Quote verdict; paid receipt issued, if any; source observation time.
- Whether the operator completed the intended downstream task.
- Whether they submitted a second claim, used the receipt downstream, requested
  a recurring check, or paid for another witness.
- Failure or refusal reason, support minutes, and retrieval cost where known.

A trial passes the proposed initial commercial test if at least one external
operator demonstrates one of those four follow-on actions. Report which action:
a request for recurrence is not payment, and downstream use is not recurring
revenue. Internal tests, our wallets, and induced purchases are not external demand.

If nobody follows through, report that result for this sample and distribution
attempt. Do not conclude that no market exists. Do not build recurrence machinery
merely because the invitation mentions recurring checks.
